# Ponytail — MIT-licensed upstream coding skills

Original author: Dietrich Gebert. Canonical source: https://github.com/DietrichGebert/ponytail at commit `e3ba2aa6f1e6f0bc4d69eb09c9f0d0a93af56156`.

The six upstream `SKILL.md` texts are reproduced without modification. Each skill also carries a verbatim copy of the upstream root MIT license as `LICENSE.txt`. Therefore the complete local directory trees are **not** claimed upstream-exact. Per-file provenance lives in `registry/vendor-ponytail.json`; updates require manual review.

Included: `ponytail`, `ponytail-review`, `ponytail-audit`, `ponytail-debt`, `ponytail-gain`, `ponytail-help`.

For Antigravity IDE install the bundle with `./install.sh "$HOME/.gemini/config/skills" --flat`, then use the optional global rule in `adapters/antigravity/`. CLI has a separate global skills path. Claude/Codex hooks, MCP server, mode tracking and benchmark runner scripts are **not** installed by this bundle.
