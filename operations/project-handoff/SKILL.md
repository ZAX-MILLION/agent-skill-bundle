# project handoff

1. Read actual repo instructions, task docs, branch/PR state and verified live version. Do not mistake old chats for live evidence.
2. Maintain private status with DONE, IN PROGRESS, BLOCKED, NOT STARTED, last verification, decisions, constraints and next step.
3. Never overwrite existing AGENTS.md/GEMINI.md or plans without preserving requirements.
4. Do not store credentials or private admin details in public Git. Clearly separate planned, committed, merged, deployed and live-verified work.

For code/config/security work also use `security/secure-by-default-development` and `process/verification-before-completion`.
