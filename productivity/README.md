# Productivity skills

The canonical [i-have-adhd](https://github.com/ayghri/i-have-adhd) source (Ayoub Ghriss, MIT) is copied unchanged at `productivity/i-have-adhd/SKILL.md`. Antigravity's persistent, user-global style setup is documented at `adapters/antigravity/adhd-primary-rule.md`, outside the upstream skill. The bundle does not install or execute third-party hooks or modify private user configuration.
