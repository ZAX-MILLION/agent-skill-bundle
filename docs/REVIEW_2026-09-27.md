## Packaging and permissions

- Full vault: 174 unique names; strict on-demand exposes only `i-have-adhd`
  and `skill-retrieval-routing` in each native host skill root. The other 172
  stay in the one reviewed source checkout. An MCP index is a discovery layer,
  not a substitute for local referenced files.
- The official n8n source files and the added Superpowers diagnostic package
  are hash-pinned in `registry/vendor-third-wave.json`; the eight ECC sources
  and license copies are hash-pinned in `registry/vendor-ecc.json`. The
  bundle's four routing adapters are original local instructions, not false
  copies of external products.
- Do **not** run upstream PAUL/ECC installers, n8n plugins or OpenMontage media
  providers automatically. Do **not** add global hooks, change MCP configuration,
  enable cloud sync, authorize an n8n instance or grant filesystem/SSH privileges
  through a skill install. Separate runtime setup requires the owner's approval.
- A public-content gate scans current tracked content only. Historical Git
  exposure noted in `SECURITY.md` remains a separate rotation/history task,
  not resolved by this review.
