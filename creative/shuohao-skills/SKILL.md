# shuohao-skills — six-workflow source router

Original local adapter, **not** a redistributed copy of the six full upstream skills. Source: [eternityspring/shuohao-skills](https://github.com/eternityspring/shuohao-skills), reviewed at `ef4ac0c313c7eeb1f918db5f0f0eb319745900bc`, Apache-2.0. Its original skills contain reference material, JS/Node scripts and image assets that must stay together. Neither a `SKILL.md` alone nor this router will produce assets automatically.

Choose the exact workflow and read it from the reviewed full upstream checkout:
- `character-refs`: visual character reference anchor and views, relevant to **original** Timberguard character concept/reference planning; outputs are reference sheets, not guaranteed directly uploadable modular game sprites.
- `novel-outline`: adapt long-form narrative into short-drama structure.
- `novel-characters`: character dossier, voice/image prompts and consistency.
- `novel-art`: scene/prop visual direction and consistency.
- `novel-script`: scripted scenes and timing.
- `novel-storyboard`: frame/shot plan and export package.

Use only the selected full upstream skill directory including assets, refs, scripts and license. The source README includes Chinese and English guides. Confirm Node/runtime and generation-provider availability before invoking scripts or promising images; verify whether paid APIs, content upload or other provider setup is required. Review scripts, external prompts and file writes before execution, keep private stories/assets in their own workspaces, and respect copyright/originality. Do not infer that a character concept sheet is a production-ready transparent game asset pack.

On-demand options: install just the selected upstream skill into the host's reviewed project skill root, or keep a separate local upstream checkout and instruct the agent to read that directory. Do not bulk-install all six into native startup discovery or mirror third-party binary assets into this public bundle.
