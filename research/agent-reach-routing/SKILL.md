# Optional Agent Reach routing

Canonical external project: https://github.com/Panniantong/Agent-Reach . This is an original safety adapter, not a verbatim upstream skill or the CLI runtime.

1. Prefer native authorized connectors for existing connected services such as private GitHub repositories.
2. Confirm the CLI is installed locally. A skill alone does not provide commands, channels or permissions. If absent, use the review-first installation guide in adapters/antigravity/external-research.md.
3. Use read-only environment diagnostics first. Redact any configuration or session information from reports. A doctor status is not proof of successful content retrieval.
4. Limit initial work to explicitly requested public pages, videos, RSS and public search. Third-party readers can receive the URL/query: never send private/admin URLs, token-bearing links or confidential records to them.
5. Do not extract, paste, export or store browser cookies in chat/Git. Authenticated social platforms, browser profiles, optional dependencies, system installation and MCP configuration need separate explicit approval and protected local storage.
6. No posting, commenting, messages, purchases, account changes, destructive actions or access-control bypass under a research request.
7. Never install or reconfigure this optional tool on the shared production VPS just to add browsing features. Verify and report the actual local capability.
