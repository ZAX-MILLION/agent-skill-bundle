# Agent project catalog

Source: https://github.com/ashishpatel26/500-AI-Agents-Projects . It is a reference catalog, not 500 Antigravity skills.

1. Match the task to a few documented examples. Prefer an already-installed skill or existing project implementation when practical.
2. Each linked project is an independent third-party source. Check its own license, maintainer, dependencies, execution behavior, permissions and test instructions.
3. Do not bulk-clone, install dependencies, fetch credentials or run scripts merely because they are linked by the catalog.
4. Borrow an architecture pattern or reviewed component only when useful, preserving attribution and applicable licenses.
5. Prototype in an isolated non-production workspace. Run tests and verify outputs before proposing deployment.
6. Never publish private project records or give a catalog example access to production by default.
