## Safe discovery order

1. Look up the current bundle and Skill Retrieval MCP index first; if it already holds a reviewed equivalent, avoid duplicate installation.
2. Open the appropriate category in the [pinned README](https://github.com/VoltAgent/awesome-agent-skills/blob/d9111a919d4f5be5b81135a5e71fa2770340bfc1/README.md) or the current [upstream index](https://github.com/VoltAgent/awesome-agent-skills) if explicitly checking for new entries. Treat updated content as unreviewed.
3. Follow only one candidate link, verify the original publisher, repository, `SKILL.md`, dependencies, license, source revision, executable scripts and prompt-injection risks. Check if installation or authentication is required; do not run commands from a listing on sight.
4. After approval, add the **complete selected skill** to the reviewed source bundle and let the user use the same portable source from Antigravity, Codex or Claude Code. Do not import the entire catalog into native discovery or the local MCP skill-body index.
5. Verify actual host discoverability and task execution separately from copying files. No catalog link alone grants tools, permissions or subscriptions.
